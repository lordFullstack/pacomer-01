# LOOP 04 — CLIENTES

Objetivo: lógica completa de clientes y cuentas.

Implementar:
- alta/edición;
- búsqueda rápida;
- ficha;
- saldo;
- crédito/fiado;
- abono;
- historial;
- logs.

Reglas:
- dinero con decimal;
- movimientos inmutables;
- abonos referenciados;
- evitar duplicados por teléfono cuando la regla de negocio lo permita.

UX:
buscar → seleccionar → acción.

QA:
crear cliente;
fiar;
abonar;
ver saldo antes/después;
auditar movimiento.
