# LOOP 10 — VELOCIDAD OPERATIVA

Auditar:
- número de clicks/taps;
- tiempos de respuesta;
- foco;
- Enter;
- atajos;
- skeletons;
- optimistic UI solo cuando sea seguro;
- consultas innecesarias;
- re-renders.

Metas:
- acciones frecuentes con 1–3 interacciones;
- pantalla de mesas usable con una mano en móvil;
- búsqueda de cliente/proveedor inmediata;
- modal de mesa sin navegación profunda.

No sacrificar trazabilidad por velocidad.
